# Fichas de repositorios y herramientas

Cada repositorio, servidor MCP, plugin o mod que llega en un guardado recibe una ficha en esta carpeta, con el nombre `<owner>-<repo>.md`.

## Estructura de cada ficha

- **Qué hace:** resumen en dos o tres frases.
- **Enlace y estado:** URL, estrellas, último commit, licencia.
- **Para qué le sirve a Angel:** la skill madre que potencia y el caso de uso.
- **Riesgos:** permisos que pide, dependencias, señales de mantenimiento.
- **Instalación propuesta:** los comandos exactos, para ejecutar en el Mac con Claude Code tras la aprobación.
- **Decisión:** pendiente, instalado o archivado, con fecha.
- **Fuente:** el guardado que lo trajo, con enlace y fecha.
