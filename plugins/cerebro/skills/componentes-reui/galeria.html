Cinco componentes de ReUI

Componentes React gratuitos (licencia MIT) que Claude instala con un comando en un proyecto con shadcn/ui. El código queda en tu proyecto para adaptarlo. Elige el que necesitas; las maquetas son representaciones propias de cada uno.

01 · Gantt

Cronograma de tareas

Tareas en una línea de tiempo. Arrastrar una barra la mueve; tirar del borde cambia su duración.

Ideal para cronogramas de proyectos, producción de contenido y lanzamientos.

npx shadcn@latest add @reui/gantt

02 · Data grid

Tabla tipo hoja de cálculo

Seleccionar un rango de celdas, copiar, pegar y escribir directo en la celda. Maneja miles de filas.

Ideal para inventarios, presupuestos y listas de clientes editables.

npx shadcn@latest add @reui/data-grid

03 · Event calendar

Calendario de eventos

Vistas de mes, semana, día y agenda. Los eventos se arrastran de un día a otro y respetan zonas horarias.

Ideal para reservas, agendas de equipo y calendarios editoriales.

npx shadcn@latest add @reui/event-calendar

04 · Filter builder

Constructor de filtros

Condiciones que se suman paso a paso, cada una con su editor de valor. Devuelve el árbol de reglas en JSON para consultar la base de datos.

Ideal para búsquedas avanzadas en paneles y tablas con muchos campos.

npx shadcn@latest add @reui/filters

05 · Cascader

Selector anidado

Una lista con niveles dentro de un solo campo: entrar a cada nivel, volver con las migas de pan y buscar.

Ideal para categorías, ubicaciones (país › ciudad) y carpetas.

npx shadcn@latest add @reui/cascader
