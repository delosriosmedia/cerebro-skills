# Interfaz visual

**Alcance:** Aquí viven los criterios sobre jerarquía visual, espaciado, estados interactivos, consistencia estética y densidad en pantallas.

## Criterios

### C-001 · Tarjeta de métrica con comparación y contexto
- **Regla:** cada tarjeta de métrica muestra tres capas: el número grande como protagonista, una línea de comparación con el periodo anterior («+8,2 % vs octubre») y una línea de contexto que da escala («77 % de 2.847 cupos»). La métrica principal ocupa la tarjeta más grande y lleva el color de acento.
- **Cuándo aplica:** paneles de administración, tableros de analítica y resúmenes de cuenta.
