# Biblioteca de prompts

Esta carpeta almacena prompts reutilizables y aprobados para uso directo.

## Convención de archivos

Cada prompt se guarda en un archivo propio con el nombre `<tema>-<nombre-corto>.md`.

## Estructura de cada archivo

Cada archivo de prompt incluye estas secciones:

- **Título:** nombre claro del prompt.
- **Para qué sirve:** descripción breve del objetivo y el contexto de uso.
- **Prompt:** el texto completo dentro de un bloque de código.
- **Variables a reemplazar:** lista de marcadores editables junto con su significado.
- **Herramienta o modelo recomendado:** modelo, plataforma o versión ideal para ejecutarlo.
- **Fuente:** enlace y fecha de origen del prompt.
