1 · PDF en serie

pdfme

PDF con diseño fijo a partir de una plantilla JSON y tus datos. Trae un diseñador visual para armar la plantilla arrastrando textos, tablas, imágenes y QR.

Ideal para facturas, certificados, cotizaciones e informes con el mismo formato.

Pídelo así: «Con pdfme, genera un certificado por cada asistente de esta lista».

2 · Documento a datos

Unstract

Los mismos campos de cada documento, en JSON. Defines qué sacar con prompts y lo publicas como API o como tubería hacia tu base de datos.

Ideal para facturas, contratos o formularios escaneados que llegan seguido.

Pídelo así: «Con Unstract, saca cliente, valor y fechas de cada contrato y guárdalos en Supabase».

3 · Análisis en lote

DocETL

Tablas con categorías, temas o resúmenes de cientos de documentos. Describes la tubería en YAML (map, reduce, filtrar) y DocETL la optimiza en costo y precisión.

Ideal para transcripciones, comentarios o guardados que quieres entender en conjunto.

Pídelo así: «Con DocETL, agrupa por tema las transcripciones de mis 200 videos».

4 · Chat en tu app

assistant-ui

Un chat con IA en React con respuestas en streaming, adjuntos, historial y una tarjeta propia para cada herramienta que ejecuta el modelo.

Ideal para poner un asistente dentro de una app o un panel propio.

Pídelo así: «Con assistant-ui, agrega un chat a mi app que consulte el cerebro».
