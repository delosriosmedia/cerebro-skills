# Herramientas no-code

**Alcance:** Aquí viven los criterios sobre diseño de automatizaciones, disparadores, nodos y mantenimiento en plataformas visuales no-code.

## Criterios

### C-001 · Paga la infraestructura, construye la automatización simple
- **Regla:** Paga los servicios de infraestructura (hosting, envío de correo, base de datos, dominios, pagos). Las automatizaciones simples que venden las herramientas por suscripción, como responder comentarios, vigilar carpetas, recoger una lista de espera o programar publicaciones, constrúyelas con Claude sobre esa infraestructura.
- **Cuándo aplica:** Al armar el stack de un producto o proyecto nuevo y cada vez que una tarea parezca pedir otra suscripción (Zapier, ManyChat, Mailchimp, Buffer, HubSpot). Ejemplo del guardado: infraestructura comprada por unos 25 USD al mes (Cloudflare, Resend, Supabase, Stripe) y, construidos con Claude, el bot de respuestas de Instagram, el vigilante de carpetas, la lista de espera, el ayudante de publicaciones en X, el CRM, el marcador y el motor de prospectos.
- **Fuente:** [Carrusel de @danielwelsh_routiq](https://www.instagram.com/p/DgB7U_ilNel/) · 2026-11-21
