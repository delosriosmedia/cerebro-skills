# Nueve repositorios de GitHub para proyectos con IA

**Qué es:** un carrusel de diez diapositivas con nueve repositorios de código abierto para armar productos con IA. Cada diapositiva muestra la interfaz de la herramienta y tres beneficios.

**Fuente:** [Instagram · rakeshmahantiai1](https://www.instagram.com/p/Df90pdYE1M2/) · guardado el 2026-11-25.

## Con ficha en `repos/`

Angel eligió estas cuatro el 2026-11-25. El hook `sugerir-herramientas-ia.sh` las sugiere en contexto y la skill `selector-herramientas-ia` muestra lo que produce cada una.

| Repositorio | Qué hace | Ficha |
| --- | --- | --- |
| Unstract | Documentos sueltos a JSON estructurado con prompts | `repos/zipstack-unstract.md` |
| DocETL | Procesa lotes de documentos con LLM y devuelve tablas | `repos/ucbepic-docetl.md` |
| assistant-ui | Componentes de chat con IA para React | `repos/assistant-ui-assistant-ui.md` |
| pdfme | PDF desde plantillas JSON, con diseñador visual | `repos/pdfme-pdfme.md` |
